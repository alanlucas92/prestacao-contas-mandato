💡 DICAS PRO
============

1. PRIMEIRA VEZ NO GITHUB?
   → Siga exatamente o guia em GITHUB_SETUP.md
   → Não tenha pressa, faça passo-a-passo
   → Teste localmente primeiro

2. CUSTOMIZAR CORES?
   → Tudo está em styles.css (linhas 10-27)
   → Só precisa mudar as variáveis :root

3. ADICIONAR NOVA SEÇÃO?
   → Copie uma <section class="tema">
   → Mude o id e conteúdo
   → Adicione um link no nav-dots

4. MELHORAR PERFORMANCE?
   → Comprima as imagens
   → Use lazy loading em produção
   → Minifique CSS/JS

5. MOSTRAR NO PORTFÓLIO?
   → Screenshots no README
   → Link ao vivo (GitHub Pages ou Netlify)
   → Mencione tecnologias usadas
