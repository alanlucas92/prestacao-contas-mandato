💡 DICAS IMPORTANTES | IMPORTANT TIPS
════════════════════════════════════════════════════════════════════════════

👉 PROFISSIONALISMO
   ✅ Commits descritivos = "feat: add smooth scroll navigation"
   ✅ README bem feito = Primeira coisa que veem
   ✅ Screenshots no README = Mostra resultado
   ✅ Link ao vivo = Impressiona recrutadores

👉 CUSTOMIZAÇÃO
   🎨 Cores? Edite em styles.css (linhas 10-27)
   📝 Conteúdo? Edite em index.html
   ➕ Novas seções? Copie uma <section> e mude o ID
   🖼️ Imagens? Coloque em assets/imagens/

👉 PERFORMANCE
   ⚡ Comprima imagens (TinyPNG)
   ⚡ Minifique CSS para produção
   ⚡ Use lazy loading se tiver muitas imagens
   ⚡ Teste no PageSpeed Insights

👉 GIT WORKFLOW
   📝 Commit frequentemente (pequenos, descritivos)
   🔀 Use branches para features
   ✅ Sempre faça pull antes de push
   🧹 Mantenha histórico limpo
